## 통합 규칙

1. 감사 보고서의 항목 번호와 결론은 역사적 근거이므로 수정하지 않는다.
2. 새 기능의 현재 상태는 `docs/12`에만 추가한다.
3. 수동 QA 절차는 `docs/13`에만 추가하고, 사용자용 작업지는 필요한 배치만 발췌한다.
4. 이 폴더의 문서에서 현재 상태를 설명해야 할 때는 요약을 복사하지 말고 `docs/11`·`docs/12`·`docs/13`으로 링크한다.
