# MLsoft 3차 브라우저 캡처 기반 사용자 QA 작업표

## 사용 방법

이 문서는 자동으로 확인한 사실과 사용자가 실제 계정으로 확인할 항목을 분리한 작업표다. 자동 증거만으로 인증 이후 화면을 PASS로 확정하지 않는다.

각 항목을 실행한 뒤 아래 형식으로 결과를 보내면 된다.

~~~text
I-1 PASS — 관찰 내용, 사용 계정/역할, 캡처 또는 재현 경로
C-1 FAIL — 실제 화면에서 확인한 문제와 재현 순서
M-2 UNKNOWN — 계정 또는 테스트 데이터가 없어 확인하지 못함
~~~

결과를 받은 뒤에만 마스터 체크리스트와 QA 보고서에 PASS/FAIL/UNKNOWN을 반영한다.

## 사전 조건과 안전 주의사항

1. 관리자 승인 QA에는 완료된 관리자 계정 1개가 필요하다.
2. I-1~I-4에는 서로 다른 온보딩 대기 계정 2개와 자동 승인 기간 안의 별도 계정 1개가 필요하다.
3. DemoDataInitializer가 만든 DB 사용자는 Google OAuth로 로그인할 수 있는 계정이 아니다.
4. 실제 @mlsoft.com Google Workspace 계정 또는 테스트용 OAuth 계정을 사용한다.
5. Google이 Windows 보안 키·패스키를 요구하면 실제 보안 키/패스키를 사용하거나 취소한다. 임의 OAuth 토큰, 가짜 authorization code, 다른 사용자의 쿠키를 사용하지 않는다.
6. 계정과 개인정보가 캡처에 포함되면 캡처를 공유하기 전에 이메일·토큰·쿠키를 가린다.
7. 정책·부서·구성원 데이터를 바꾸는 단계는 테스트 데이터임을 확인한 뒤 실행하고, 운영 DB에서는 실행하지 않는다.

## 0. 자동 관찰 결과

### A-1. 로컬 로그인 화면

- 주소 http://localhost:5173/login을 Orca 브라우저에서 열었다.
- 연차ON 제목, Google 로그인 버튼, @mlsoft.com 제한 문구가 표시됐다.
- 결과: 자동 관찰 완료
- 사용자 결과: 해당 없음

### A-2. OAuth 진입

- Google 로그인 버튼을 누르면 accounts.google.com 로그인 화면으로 이동한다.
- 이메일 입력과 Google 계정 인증이 필요하다.
- Windows 보안 키 창은 Google 외부 인증 절차다.
- 결과: 자동 관찰 완료
- 사용자 결과: 해당 없음
- 증거: [Orca 캡처 로그](./캡처-2026-08-24/증거-04-오르카-브라우저-캡처.md)

### A-3. 로그인 없이 API 접근

- auth/me, departments, leaves/my, schedules, admin/configs는 로그인 없이 401을 반환했다.
- 결과: 자동 관찰 완료

## 5. 현재 차단 사항

현재 자동 확인으로는 로그인 화면과 Google OAuth 진입까지 확인됐다. Google Workspace 테스트 계정이 없으면 I-1~I-4 및 인증 이후 C/M 항목은 UNKNOWN으로 남겨야 한다. 실제 사용자가 계정으로 실행한 결과를 받기 전에는 PASS/FAIL을 확정하지 않는다.
