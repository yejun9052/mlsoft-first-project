# 사용자 QA 작업지 — 모바일 캘린더·공휴일

## 현재 자동 관찰

- `http://localhost:5174/login` 로그인 화면과 Google OAuth 진입을 확인했다.
- 로그인하지 않은 상태에서 `/calendar`에 접근하면 `/login`으로 돌아간다.
- 로그인 없는 `/api/auth/me`는 HTTP 401을 반환한다.
- 실제 OAuth 계정 없이 인증 이후 화면을 PASS/FAIL로 확정하지 않는다.

## 준비

- 실제 `@mlsoft.com` Google Workspace 테스트 계정 1개
- 데스크톱 브라우저와 모바일 에뮬레이션 또는 실제 휴대전화
- 공휴일 하루에 개인 일정·연차 표시 데이터가 2건 이상 있는 테스트 상태
- 운영 DB에는 임의 SQL을 실행하지 않는다. 필요하면 로컬 테스트 DB만 사용한다.

## 실행 항목

| 번호 | 절차 | 기대 결과 | 결과 |
|---|---|---|---|
| T-1 | 데스크톱 캘린더에서 같은 날짜에 일정·연차를 3건 이상 만들고 `...더보기`를 누른다 | 하루 상세 모달에 해당 날짜의 전체 항목과 공휴일이 표시되고, 닫은 뒤 캘린더가 유지된다 | |
| N-4 | 공휴일 하루에 개인 일정·연차 표시 데이터를 2건 이상 준비하고 데스크톱/모바일 캘린더를 확인한다 | 데스크톱 `...더보기` 개수에 공휴일이 포함되고 상세 모달에 같은 목록으로 표시된다. 모바일은 공휴일 사각 마커와 선택일 하단 공휴일 행을 표시하며 `...더보기`는 없다 | |
| T-8 | 모바일 캘린더에서 날짜를 누른다 | 아래에 선택 날짜·요일·일정 목록·`M월 D일에 추가 +`가 보이고, 셀 안에는 일정 텍스트 대신 색 마커가 보인다. 모바일에는 `...더보기`가 없다 | |
| T-9 | 모바일 캘린더에서 좌우로 50px 이상 스와이프한다 | 왼쪽은 다음 달, 오른쪽은 이전 달로 이동하고 세로 스크롤은 월을 바꾸지 않는다 | |
| 추가-1 | 모바일에서 2일 이상 이어지는 일정을 확인한다 | 가로줄이 날짜 숫자와 겹치지 않고, 각 날짜 숫자 아래에 작은 색 사각 마커가 여백을 두고 정렬된다 | |
| 추가-2 | 모바일 신청 시트에서 `날짜 더 선택하기`를 누른다 | 신청 시트가 닫히고 선택 모드가 되며, 날짜를 여러 개 고른 뒤 `선택 완료하기`를 누르면 선택 날짜가 유지된 신청 시트로 돌아온다 | |

## 회신 형식

```text
T-8 PASS — 8월 24일 선택 시 하단 목록과 추가 버튼 확인
추가-1 FAIL — 25일 마커가 숫자와 2px 겹침
```

실제 화면에서 관찰한 내용과 캡처를 함께 보내면, 그 증거만 기준으로 마스터 체크리스트와 QA 보고서에 회수한다.
