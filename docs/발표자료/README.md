# 발표자료

프로젝트 전체를 설명하는 장표. **미완성본**으로 표시해 두었다 — 아직 운영에 올리지 않았고 기능이 계속 붙는다.

두 벌이 있고 **용도가 다르다.** 겹치는 내용을 서로 복사하지 않는다.

| 파일 | 누가 보나 | 내용 |
|---|---|---|
| `연차ON-프로젝트-소개-2026-09-11.pptx` | **회사 담당자** (개발자 아닐 수 있음) | 21장. 큰 기능 한 줄씩 + 흐름도 9장 + 아키텍처 3장 + 라이브러리 표. 방문 예고·배경 설명 없이 소개만 |
| `deck-소개-생성.py` | — | 위 소개 장표의 생성 스크립트. **원본은 이쪽** |
| `브리프-소개-ppt-2026-09-11.md` | — | 소개 장표를 만들 때 Codex에 준 브리프. 제작 중 코드 대조로 정정한 3곳이 적혀 있다 |
| `연차ON-프로젝트-설명(미완성본)-2026-09-10.pptx` | **개발자** (온보딩·인수인계) | 28장. WBS 9개 대분류 + 설계 결정 5개 + 남은 작업·배포 |
| `deck-생성.py` | — | 위 WBS 장표의 생성 스크립트. **원본은 이쪽** |

## WBS 장표(개발자용) 구성

| 슬라이드 | 내용 |
|---|---|
| 1~2 | 표지 · 읽는 법(상태 배지·번호 체계·발표 시 쓰는 법) |
| 3~6 | 개요 · 규모 실측 · 스택과 구조 · 인증 흐름 |
| 7 | WBS 전체 지도 (9개 대분류) |
| 8~18 | WBS 상세 — 1 인증·온보딩 / 2 연차 / 3 복리후생 / 4 캘린더 / 5 조직·수명주기 / 6 정책 / 7 이메일 / 8 스케줄러 / 9 감사 |
| 19~24 | 설계 결정 A~E — 회차 창, 파생 필드, 스케줄러 경계, 스키마 함정, 보안 판단 |
| 25~28 | 검증 현황 · 남은 작업 · 배포 절차 · 마무리(피드백 항목) |

## 갱신 방법

기능이 추가되면 `deck-생성.py`의 해당 WBS 항목과 표지 날짜를 고치고 다시 돌린다.
장표를 파워포인트에서 직접 고치면 다음 갱신 때 덮어써진다.

```powershell
pip install python-pptx
python docs/발표자료/deck-생성.py "docs/발표자료/연차ON-프로젝트-설명(미완성본)-2026-09-10.pptx"
```

수치는 실측값이다 (2026-09-10 기준 API 88 · 화면 17 · 테이블 21 · 설정 12 · 테스트 832).
갱신할 때 문서 값을 그대로 옮기지 말고 코드를 다시 센다 — 엔티티 수를 잘못 세고 있던 전례가 있다.

내용이 `docs/12-남은-작업.md`와 어긋나면 그쪽이 맞다. 상태의 단일 원본은 계속 docs/12다.
