# 05. 디자인 가이드 ("연차ON" 딥 코발트 글래스 테마)

> 출처: `연차 관리 프로그램 디자인/design_handoff_annual_leave/` (.dc.html 하이파이 핸드오프)
> 기준 해상도 1480×864 데스크탑. 마크업은 레퍼런스일 뿐, React + Tailwind로 재구현한다.
>
> **2026-08-05 개편**: 기존 플랫 다크 네이비 → **딥 코발트 글래스**로 전면 교체.
> 서피스를 미드나잇까지 내리고, 카드·패널을 반투명 글래스(블러)로 바꾸고, 액센트를
> 단색 파랑에서 **코발트→시안 그라데이션**으로 확장했다. 토큰 *이름*은 그대로 두고
> *값*만 바꿔, 페이지에 흩어진 유틸리티 클래스가 수정 없이 새 팔레트를 따라오게 했다.

**액센트 그라데이션** (Primary 버튼·게이지·브랜드 마크·활성 표시):
`linear-gradient(135deg, #22d3ee 0%, #2563eb 55%, #1d4ed8 100%)`

**배지 틴트 배경**: 승인 `rgba(46,230,168,.12)` / 대기 `rgba(251,191,36,.13)` / 반려 `rgba(251,113,133,.13)` / 시안 `rgba(34,211,238,.12)`
— 글래스 표면 위에서는 틴트만으로 경계가 흐려지므로 **같은 색 `ring-1 ring-inset`을 함께 두른다.**

### 글래스 서피스 규칙
| 유틸리티 | 용도 | 구성 |
|---|---|---|
| `glass` | 카드·패널 기본 | `navy-card` 72% + `blur(20px) saturate(140%)` |
| `glass-strong` | 모달·사이드바·툴팁 (뒤를 가려야 하는 면) | `navy-card` 88% + `blur(28px) saturate(150%)` |
| `glass-edge` | 유리 모서리 1px 하이라이트 (`::before`) | 시안→화이트 가로 그라데이션 |
| `ambient-glow` | 앱 셸/풀스크린 바닥 광원 | 코발트(좌상) + 시안(우하) radial, `fixed`, `z-index:-10` |

**주의**: `ambient-glow`는 `z-index:-10` 고정 레이어라, 그 위에 불투명 배경을 깔면 글로우가 가려진다.
→ 앱 배경은 `body`의 `bg-navy-app` 하나로만 칠하고 셸/콘텐츠는 투명하게 둔다 (`Layout.jsx`).

### 타이포그래피 — **Pretendard** (CDN: jsdelivr pretendard@v1.3.9)
| 용도 | 굵기/크기 | 비고 |
|---|---|---|
| 페이지 타이틀 | 700 / 24px | letter-spacing -0.03em |
| 카드 타이틀 | 600 / 15px | letter-spacing -0.01em |
| 히어로 숫자(잔여 연차) | 800 / 52px | **`accent-gradient-text`**, -0.04em |
| 통계 숫자 | 700 / 28px | 숫자는 전부 `tabular-nums` |
| 본문/값 | 500~600 / 13~14px | |
| 라벨/메타 | 500 / 11~13px | |
| 사이드바 섹션 라벨 | 600 / 10px | letter-spacing 0.18em, `#435775` |

**`accent-gradient-text` 사용 주의** — `-webkit-text-fill-color: transparent`를 쓰는데 이 속성은 **상속된다.**
단위(`일`)처럼 다른 색이어야 하는 텍스트는 그라데이션 span **밖에 형제로** 둘 것 (`Stat.jsx` 참고).
`color`를 먼저 깔고 `-webkit-text-fill-color`로 투명화하는 선언 순서도 유지 — 뒤집으면 미지원 환경에서 글자가 사라진다.

### 간격·라디우스·섀도우
- 콘텐츠 패딩 26×30px, 카드 패딩 18~26px, 카드 gap 14~16px
- radius: 윈도우 20 / 카드 18 / 버튼·입력 11 / 배지 999(pill)
- 섀도우: 카드 `0 24px 64px -16px rgba(2,6,18,.9)`, Primary 버튼 `0 8px 24px -8px rgba(37,99,235,.65)`,
  글로우 `0 0 32px -6px rgba(34,211,238,.4)` (hover lift·활성 밑줄에 사용)
- **사이드바 236px 고정**, 콘텐츠 flex:1

## 화면 구조 (5개)

### ① 사이드바
로고("연차ON") → MENU 섹션(대시보드/연차 신청/사용 내역/팀 캘린더/복리후생/내 정보) → 관리자 섹션(결재 관리[배지]/구성원 관리/연차 정책) → 하단 유저 카드(아바타+이름+팀·직책, margin-top:auto)
- 사이드바 자체가 `glass-strong` 면 — 뒤 앰비언트 글로우가 은은히 비친다
- 활성 메뉴: 배경 `rgba(37,99,235,.12)` + 텍스트 `#7dd3fc` + 아이콘 시안,
  **좌측 3×20px 그라데이션 바**(기존 6px 도트에서 교체 — 세로 바가 훑어 읽기 쉽다)

### ② 대시보드
헤더("내 연차 현황" + 날짜·소속 서브 + 회계연도 칩) → **박스 없는 통계 스트립**(잔여 연차 히어로 46px | 소멸 예정 | 결재 대기 + 우측 빠른 신청 버튼들[+연차/반차/경조사]) → **팀 연차 캘린더 카드**(flex:1, 7×5 그리드, gap 6px)
- 캘린더 셀: 내 연차 = 파랑 틴트+보더, 동료 연차 = 초록 틴트, 공휴일 = 빨강 틴트, 일요일 숫자 빨강

### ③ 연차 신청
2컬럼 (폼 flex:1.7 / 요약 flex:1)
- 폼: 휴가 종류 칩(연차/오전 반차/오후 반차/경조사/병가) → 사용 기간(시작~종료 + 일수 배지) → 사유(멀티라인) → **결재 라인(승인자 칩 → 화살표 → 서브 승인자 칩)**
- 요약 카드: 현재 잔여 / 신청 일수 / **신청 후 잔여(800/22px 강조)** + [신청하기(Primary)] [임시저장(Secondary)]

### ④ 사용 내역
헤더+필터 칩(연도/종류/상태) → 통계 스트립(총부여/사용/잔여/소멸예정) → 테이블 카드
- 테이블 그리드: `120px 100px 190px 80px 1fr 100px` (신청일/종류/기간/일수/사유/상태배지)

### ⑤ 복리후생
3열 카드 그리드 (경조사♥빨강 / 건강검진＋초록 / 자기계발◈파랑 / 명절선물◆노랑 / 동호회●보라 / 리프레시☀사이안)
- 카드: 아이콘 박스 44px → 타이틀 → 설명 → 하단(금액·한도 + 상태 태그)

### ⑥ 결재 관리 (관리자)
탭(대기[배지]/승인/반려, 활성 = 하단 2px 파랑 보더) → 결재 카드 리스트
- 카드 가로 1행: 신청자(180px, 아바타+이름+팀) | 종류·일수(130px) | 기간(170px) | 사유(flex:1, ellipsis) | [반려(빨강 아웃라인)] [승인(Primary)]

## Tailwind 설정 — v4 CSS-first

**`tailwind.config.js`는 없다.** Tailwind v4의 CSS-first 방식이라 토큰은 전부
`frontend/src/index.css`의 `@theme` 블록에, 커스텀 유틸리티는 `@utility` 블록에 있다.
(아래는 형태만 보여주는 발췌 — 실제 값의 단일 출처는 `index.css`다.)

```css
@theme {
  --color-navy-app: #050b18;   --color-navy-content: #070f1f;  --color-navy-card: #0d1728;
  --color-accent: #2563eb;     --color-accent-light: #7dd3fc;  --color-accent-cyan: #22d3ee;
  --color-ink-hi: #eaf3ff;     --color-ink-body: #c3d3e8;      /* … */
  --radius-card: 18px;         --shadow-glow: 0 0 32px -6px rgba(34, 211, 238, 0.4);
}

@utility glass { /* 반투명 + backdrop-blur */ }
@utility accent-gradient { /* 코발트→시안 면 */ }
@utility accent-gradient-text { /* 위 그라데이션을 글자에 클리핑 */ }
@utility ambient-glow { /* 바닥 광원 레이어 */ }
```
