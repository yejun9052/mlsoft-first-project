## H. 알려진 미구현 — 테스트해서 "안 된다"고 보고할 필요 없는 것

QA 중에 발견해도 이슈로 올리지 말 것. 이미 파악돼 있고 `docs/12`에 있다.

- **개인 일정 삭제·수정 UI 없음** — API(`DELETE`/`PUT`)는 있으나 화면 버튼이 없다.
  잘못 등록하면 화면에서 뺄 방법이 없다. **다음 작업 1순위.**
- **내 일정 목록 화면 없음** — `GET /api/schedules/me`는 있으나 페이지가 없다.
- 공휴일이 mock이다 — `frontend/src/mocks/data.js`. 실제 공휴일과 다를 수 있다 (I-6).
- 연차 자동 기산·리셋·월차·생일 반차가 **안 돈다** — 스케줄러 `@Scheduled` 0건.
  관리자 화면의 리셋 이력은 영구히 빈 목록이다.
- 이메일이 **한 통도 안 나간다** — 발송 인프라 미구현.
- 서브 승인자 목록이 하드코딩이다 (`constants/approvers.js`, F-4).
- 역할 변경이 재로그인 전까지 화면에 미반영 (F-7).
- 부서 3단계 방지가 UI에만 있다 — API 직접 호출로는 뚫린다.
- 입사일을 본인이 신고한다 — `1990-01-01`을 넣으면 연차 25일 자가 부여 (S-1).
