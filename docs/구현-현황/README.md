## 왜 폐기했나

이 폴더는 2026-07-11(코드 `0cac59f`) 기준 스냅샷이었고, 그 뒤 한 달 동안
`백엔드.md`가 "미구현"으로 적어 둔 API가 대부분 구현됐다 — 사용자·부서·복리후생·
처리 이력·관리자 설정이 전부 들어왔고 엔드포인트는 11개에서 **49개**가 됐다.
프론트도 "mock UI"에서 실 API 연동으로 넘어갔다.

**상태 문서를 3개 병렬로 두는 구조 자체가 원인이었다.** 백엔드·프론트엔드·실행 환경으로
쪼개 놓으니 기능 하나를 구현할 때마다 세 파일을 같이 고쳐야 했고, 실제로는 아무도 안 고쳤다.
docs/11이 한 파일에서 흐름과 상태를 같이 다루므로 갱신 지점이 하나로 줄어든다.
