## 프로젝트 폴더 구조

```
mlsoft-leave-system/
├── backend/                      # Spring Boot 4 (Java 21) — 도메인별 패키지
├── frontend/                     # React 19 + Vite + Tailwind v4 (CSS-first)
├── docs/                         # 이 문서 폴더
├── Dockerfile                    # 3단계 멀티스테이지 → 단일 컨테이너·단일 포트 8080
├── docker-compose.prod.yml
├── CLAUDE.md                     # Claude Code용 프로젝트 지침 (요약본)
├── AGENTS.md                     # Codex CLI 자동 로드용 지침
├── .claude/
│   ├── agents/                   # Claude Code 서브 에이전트 4개
│   └── commands/                 # /dev, /save-session, /load-session
├── .codex/agents/                # Codex 서브 에이전트 3개 (감사·테스트·리뷰)
├── 연차 관리 프로그램 디자인/       # 디자인 핸드오프 (.dc.html)
└── 참고자료/
    ├── MLsoft/                   # 이전 프로젝트 원본 (분석용 클론)
    │   └── 전달받은참고자료/       # 회사에서 받은 PTO 시스템 설계 문서
    └── MLsoft-분석보고서.md       # 이전 프로젝트 종합 분석
```
