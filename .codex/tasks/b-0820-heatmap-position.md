## B-1. 연차 사용 히트맵 — 사용자 요구 원문

깃 잔디 그래프 형태의 Contribution Calendar를 **내 정보**와 **팀 관리** 두 곳에.

- **내 정보** — 내가 **승인받아 사용한** 연차 날짜를 초록으로. 사용일이 많을수록 진하게
- **팀 관리** — 그 날짜에 연차를 쓰는 **팀원 수**. 인원이 많을수록 진하게
- 칸에 마우스를 올리면 **날짜 + 사용 일수(또는 인원 수)** 툴팁
- **연도 선택**으로 이전 기록도
- **주말과 공휴일은 연한 회색**으로 구분
- **승인 완료된 연차만** 반영. 대기·반려는 표시하지 않는다

### 먼저 판단할 것 (결정 표에 쓸 것)

1. **지금 API로 1년치를 그릴 수 있는가.** 연차 캘린더 조회는 **월 단위**다 —
   그대로면 12번 부르게 된다. **연 단위 조회 API가 필요한지 판단하고, 필요하면 만들어라.**
   기존 엔드포인트를 바꾸지 말고 새로 낼 것
2. **반차를 어떻게 셀 것인가** — 이 시스템은 `LeaveType`에 단가가 있다(종일 1.0 / 반차 0.5).
   "사용 일수"가 0.5일 수 있다. 색 단계를 며칠 기준으로 나눌지 함께 정할 것
3. **팀 관리 쪽 "팀원"의 범위** — 내 부서만인지 하위 부서까지인지.
   `TeamPage`가 이미 팀원을 어떻게 가져오는지 보고 **그것과 같은 기준**을 쓸 것
4. **한 해가 가로로 안 들어가면** 어떻게 할지 (깃은 53주 × 7일이다).
   가로 스크롤인지 줄바꿈인지 — 모바일 1단계에서 정한 브레이크포인트를 참고할 것
5. **툴팁을 무엇으로 만들지** — 이 저장소에 툴팁 컴포넌트가 있는지 먼저 찾아라.
   없으면 새로 만들되 **호버뿐 아니라 키보드 포커스로도** 떠야 한다
6. **개인정보** — 팀 히트맵은 인원 수만 보여준다. **누가 쉬는지는 넣지 마라.**
   연차 사유·이름이 툴팁에 새면 안 된다 (이 프로젝트의 마스킹 기준)

## B-2. 직책(`position`) 자가 설정

컬럼·응답·화면 표시는 **이미 있는데 값을 넣는 경로만 없다.** 실제 사원은 전부 `null`이다.

**사용자 결정**: "개인 설정 페이지에서 자기가 설정하는 방향이 좋다."
→ **내 정보 화면의 정보 수정 폼**에 직책을 더한다.

- 지금 그 폼은 이름·생년월일을 저장한다. 같은 흐름에 직책을 얹는다
- **자유 입력인지 목록 선택인지 정하고 근거를 써라.** 자유 입력이면 길이 제한이 필요하고,
  목록이면 그 목록을 어디에 둘지가 문제가 된다(하드코딩은 이 저장소가 싫어한다 —
  `PolicyConfigKey`·`ScheduleType` 같은 카탈로그 패턴을 참고할 것)
- ⚠️ **`MyInfoPage`에는 2026-08-19에 넣은 "저장 안 한 변경 붙잡기"가 있다.**
  `useUnsavedGuard`가 이름·생년월일만 보고 있으니 **직책도 그 비교에 넣어야** 한다.
  빠뜨리면 직책만 고치고 나갈 때 조용히 사라진다
- 엔티티·컬럼을 바꾼다면 `db/schema.sql`과 `db/backfill-<날짜>-<주제>.sql` **둘 다** 낼 것
  (CLAUDE.md 배포 절). `position` 컬럼이 이미 있다면 불필요하다 — **먼저 확인**

## 규칙

- **화살표 함수 컴포넌트 금지** — `export default function Name({ props })`
- 주석은 **한국어**로 **왜**를 쓴다. 기존 문체를 따를 것
- 색·반경은 `index.css`의 `@theme` 토큰만. **초록 단계도 토큰으로 낼 것** —
  히트맵 색은 새 토큰이 필요할 가능성이 높다. 넣었으면 `docs/05`에 무엇을 왜 넣었는지
- 앱은 **데이터 라우터**다. 테스트는 `createMemoryRouter` + `RouterProvider`
- 백엔드: URL kebab-case, `ResponseEntity<CommonResponse<?>>`, `BusinessException(ErrorCode)`,
  DTO는 record, 본인 식별은 `@AuthenticationPrincipal AuthUser`
- **연차 일수는 `BigDecimal`만** (double 금지, 비교는 `compareTo`)
