## 할 일

### A-1. 팀장 승격 부서 선택이 "미배정 소속"에도 뜨게 (docs/12 B-9)

**배경 — 반드시 이해하고 시작할 것.** `DataInitializer`가 **"미배정"이라는 이름의 실제
부서 행**을 만들고 신규 가입자를 거기 배속한다. 그래서 `department == null`인 계정이
사실상 없고, 2026-08-20에 만든 팀장 승격 부서 선택(`needsDepartment`)이 **실계정에서
한 번도 뜨지 않는다.**

**사용자 결정**: 미배정 부서는 **그대로 둔다.** 대신 **"부서 없음"과 "미배정 소속"을 같은
상태로 취급**해 그 확인 창이 뜨게 한다.

- `AdminMembersPage`의 `needsDepartment` 조건식을 고친다
- ⚠️ **프론트에서 이름 문자열 `'미배정'`을 비교하지 마라.** 부서 이름이 바뀌면 조용히 깨진다.
  **판별의 단일 출처를 어디에 둘지 정하고 근거를 써라.** 서버가 플래그로 내려주는 것이
  맞다고 판단되면 **필요한 백엔드 변경을 "다음 과제" 항목으로 적기만 하고 코드는 내지 마라**
  (백엔드는 다른 세션이 잡고 있다). 그동안 쓸 임시 방편이 있으면 그것도 근거와 함께
- 팀장 승격 **부서 선택지에서 미배정을 제외**한다 — 미배정 부서의 팀장은
  "부서 없는 전원의 승인자"가 되어 버린다

### A-2. 구성원 관리 퇴직 탭에 **퇴직 경과일수**

"2026-05-03 (109일 전)" 같은 형태. 표현은 정하고 근거를 써라.
`retiredAt`이 응답에 있는지 먼저 확인할 것. **없으면 코드를 내지 말고 그 사실을 보고**하라.

### A-3. 연차 사용 내역 — 사유가 길면 말줄임 + 클릭 시 모달 상세

`HistoryPage`. 긴 사유가 표를 밀어내는 것을 막는다.
- 몇 자에서 자를지 정하고 근거를 쓸 것
- **잘리지 않은 사유는 클릭 대상이 아니어야 한다** (눌러도 아무 일 없는 것은 고장으로 보인다)
- 모달은 기존 `components/ui/Modal.jsx`를 쓴다. **Modal.jsx를 수정하지 마라** —
  다른 세션이 모바일 바텀시트로 바꾸고 있다

### A-4. "팀 캘린더" → "캘린더"

표기만. 사이드바 라벨·페이지 제목 등 **사용자에게 보이는 문구**를 찾아 바꾼다.
라우트 경로(`/calendar`)와 컴포넌트 이름은 이미 캘린더이므로 건드리지 마라.

### A-5. 캘린더 월 이동 화살표가 안 보인다

사용자 지적: "캘린더 칸에 날짜를 변경하는 화살표가 너무 안 보임. 더 잘 보이는 위치로."
- 지금 어디에 어떻게 있는지 먼저 파악하고, **왜 안 보이는지**(대비·크기·위치 중 무엇인지)
  진단한 뒤 고쳐라. 위치만 옮겨서 해결되는 문제가 아닐 수 있다
- **키보드 좌우 화살표로도 월 이동**을 넣을지는 이번엔 하지 말고 판단만 적어라
  (사용자가 "추후에"라고 했다)

## 규칙

- **화살표 함수 컴포넌트 금지** — `export default function Name({ props })`
- 주석은 **한국어**로 **왜**를 쓴다. 기존 문체를 따를 것
- 색·반경은 `index.css`의 `@theme` 토큰만. `tailwind.config.js`는 **없다**
- 앱은 **데이터 라우터**다. 테스트는 `createMemoryRouter` + `RouterProvider`
- 개별 호출부에서 에러 토스트 금지 (`api/index.js` 인터셉터가 일괄 처리)
- **각 항목마다 vitest 검증을 함께 낼 것**
