# 작업: 리셋에서 재계산을 "제외"하는 것이 옳은가 — 다년 누적으로 검증

diff-reviewer가 다음을 🔴 치명으로 올렸다:

> 리셋이 `base=-5, advance=0`으로 닫은 뒤 월차 1일이 적립되면 `base=-4`가 되고 재계산으로
> `advance=4`가 부활한다 → 다음 리셋에서 이미 정산한 4일을 또 차감한다.

**상태가 재계산으로 변하는 것은 사실이다. 그러나 "또 차감"이 맞는지는 검증이 필요하다.**
`resetAnnualLeave`는 `base = newBase − advance`로 base를 **덮어쓴다**(가감이 아니다).
그러면 음수 base는 버려지므로, 오히려 advance로 옮겨 담지 않으면 빚이 사라지는 게 아닌가?

## 검증 방법 — 다년 누적 정산으로 판정해라

각 시나리오를 **연도별로 끝까지** 추적하고, 마지막에 아래 항등식으로 정답을 검증해라:

```
최종 잔여 = Σ(연도별 부여 일수) − Σ(실제 사용 일수)
```

정책 연차는 매년 15일, 리셋은 `base = newBase − advance`, `use=bonus=advance=0`으로 가정한다.

### 시나리오 A — 리셋에서 재계산 제외 (현재 구현), 리셋 후 아무 활동 없음
```
Y1: base=15, use=35        → advance=20
리셋: base = 15−20 = −5,   advance=0   (재계산 안 함)
Y2: 활동 없음
리셋: base = 15 − 0 = 15,  advance=0
```
Y3 시작 잔여는 15다. 항등식으로 계산한 정답은 얼마인가? (부여 15+15+15 = 45, 사용 35)

### 시나리오 B — 리셋에서 재계산 제외, 리셋 후 월차 1일 적립
```
리셋: base=−5, advance=0
월차: base=−4 → 재계산 → advance=4
리셋: base = 15 − 4 = 11
```
Y3 시작 잔여는 11이다. 항등식 정답은? (부여 15+15+1+15, 사용 35)

**A와 B는 같은 상태에서 출발했는데 "무관한 활동이 있었는지"에 따라 결과가 다르다.**
이게 리뷰 I-1과 같은 종류의 결함인지 판정해라.

### 시나리오 C — 리셋에서도 재계산 (제안하는 수정), 활동 없음
```
리셋: base = 15−20 = −5 → 재계산 → advance=5
Y2 활동 없음
리셋: base = 15 − 5 = 10 → 재계산 → advance=0
```

### 시나리오 D — 리셋에서도 재계산, 월차 1일
```
리셋: base=−5, advance=5
월차: base=−4 → advance=4
리셋: base = 15 − 4 = 11 → advance=0
```

### 시나리오 E — 재귀 위험 검증 (docs/09 §5의 우려)
C 방식에서 **빚이 매년 새 정책 연차보다 크면** 어떻게 되는가.
`advance=50`으로 시작해 3년치를 추적하고, advance가 단조 감소해 종료되는지 판정해라.
docs/09 §5는 "재귀적으로 이어져 추적이 불가능해진다"고 했다 — 실제로 그런가?

### 시나리오 F — 미래 승인분 재차감과의 상호작용
스케줄러 시그니처 `resetAnnualLeave(newBase, carriedUse, carriedBonus, resetDate)`에서
`carriedUse=20`(새 연도에 이미 승인된 미래 연차 20일), `advance=0`, `newBase=15`인 경우.
C 방식으로 재계산하면 `advance=5`가 되는데, 이 20일은 **새 연도에 실제로 쓰는** 연차다.
다음 리셋에서 이 5일을 차감하는 것이 **이중 차감인가, 정당한 초과분 이월인가.**
항등식으로 판정해라. docs/09 §5가 걱정한 게 이 경우로 보인다.

## 답할 것

1. A~D 각각의 정답 대비 오차 (일 단위 숫자로)
2. "리셋 제외"가 결함인가 — 그렇다면 A/B 중 어느 쪽이 틀렸나
3. E — C 방식이 종료하는가, 무한 재귀인가
4. F — 이중 차감인가 아닌가
5. **최종 판정**: 리셋에서 재계산해야 하는가, 제외해야 하는가.
   제외해야 한다면, A/B의 활동 의존성을 어떻게 없애는가.

숫자 근거 없는 답은 쓰지 마라. docs/09 §5를 읽고, 그 서술이 F 이외의 경우에도 성립하는지 판정해라.
